# Moda Urbana - Tienda de Ropa Online

Proyecto completo de e-commerce para tienda de ropa, listo para presentar.

## Cómo abrir el proyecto

1. Descarga o copia la carpeta `tienda-ropa` completa.
2. Abre la carpeta en **Visual Studio Code**.
3. Abre el archivo `index.html` con Live Server (extensión recomendada) o simplemente haz doble clic en `index.html` para abrirlo en el navegador.

> **Importante:** Usa un servidor local (Live Server) para que todo funcione correctamente con las rutas.

## Funcionalidades incluidas

### Cliente
- Página de inicio con productos destacados
- Catálogo con filtros (género, categoría, precio, orden)
- Detalle de producto (talla, color, cantidad)
- Carrito de compras (agregar, quitar, cambiar cantidad)
- Cálculo de subtotal, envío y total
- Envío gratis en compras ≥ $999
- Registro e inicio de sesión (correo + simulación Google/Facebook)
- Recuperación de contraseña (simulada)
- Proceso de compra completo (4 pasos):
  1. Dirección de entrega
  2. Método de envío
  3. Método de pago (OXXO, BBVA, PayPal)
  4. Confirmación + ticket OXXO con código de barras, monto, vencimiento y referencia

### Administrador
- Dashboard con estadísticas
- Gestión de productos (agregar, editar, eliminar)
- Inventario por talla
- Lista de pedidos
- Lista de clientes

## Tecnologías
- HTML5 + CSS3 + JavaScript (Vanilla)
- Bootstrap 5
- Bootstrap Icons
- localStorage (persistencia de datos)

## Notas para la presentación
- Los datos se guardan en el navegador (localStorage).
- Las imágenes vienen de Unsplash (necesitas internet).
- El pago OXXO es una simulación visual completa según tu boceto.
- Puedes agregar más productos desde el panel de administración.
